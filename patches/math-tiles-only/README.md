# Acellus-Zero: Math Tiles Helper Only

## Overview
A dedicated standalone patch that injects the **Math Tiles Instant Helper & Auto-Solver** without altering any other app permissions or security flags.

### What is included:
- **Instant Math Tiles Solver:** Intercepts `index-*.js` via `n2/b0.smali` to append `payload.js`.
- Bypasses the 10-second hint delay on Math Tiles.
- Visual glowing green indicator (`#00ff66`) on the winning tile slot.
- `Space` key auto-play listener.
